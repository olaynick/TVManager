# TVManagerTCL

GUI-приложение для настройки и управления телевизорами **TCL на Android TV** через ADB.
Написано на PowerShell + WPF. Запускается одним `.bat`-файлом, установка не требуется.

---

## Возможности

### Управление приложениями
- Просмотр всех установленных, системных, сторонних и отключённых пакетов
- Отключение рекламных и телеметрических сервисов TCL
- Удаление предустановленного мусора без root (`pm uninstall --user 0`)
- Восстановление удалённых пакетов (`cmd package install-existing`)
- Очистка данных приложений (`pm clear`)
- 6 категорий: Реклама и слежка, Стриминг и медиа, Лаунчеры, TCL-сервисы, Google-мусор, Системные
- Маркировка рисков: зелёный (безопасно), оранжевый (осторожно), красный (может сломать ТВ)
- Двойное подтверждение при отключении опасных пакетов
- Защита критических системных пакетов от отключения
- Экран «Отключённые приложения» для быстрого возврата пакетов
- Сквозной поиск по всем категориям сразу

### Приложения и лаунчеры
- Список всех установленных приложений с фильтрами (системные / пользовательские)
- Запуск любого приложения на ТВ одной кнопкой
- Отдельная вкладка «Лаунчеры» — список известных лаунчеров, установленных на ТВ
- Назначение стороннего лаунчера главным экраном («Сделать лаунчером»)

- Встроенная инструкция для Google TV: безопасный путь через Accessibility Service стороннего лаунчера
- Кнопки восстановления стандартных лаунчеров (Google TV, TCL)
- Предупреждение о рисках отключения штатного лаунчера

### Установка APK

- Подсказки с командами для обхода ошибок
- Установка APK, лежащего на самом ТВ (обход SELinux через `/data/local/tmp/`)

- Пометка уже установленных APK в списке

- Распаковка ZIP-архивов с APK внутри
- Защита от повторного запуска установки
- Обработка потери связи во время установки

### Файловый менеджер
- Навигация по `/sdcard/`, `/storage/`, `/data/`

- Быстрые пути: `/`, `/sdcard/`, `/sdcard/Download/`, `/storage/`, `/data/`
- Установка APK прямо из файлового менеджера (двойной клик по `.apk`)

## Веб-интерфейс для телефона

TVManager может поднять локальный HTTP-сервер на ПК, чтобы управлять телевизором прямо с телефона через браузер. Никаких дополнительных приложений устанавливать не нужно — ПК и телефон в одной Wi-Fi-сети, и всё работает.

### Как запустить

1. Подключитесь к телевизору в TVManager.
2. Откройте **Настройка → Сервис → HTTP-сервер**.
3. Нажмите **«Запустить сервер»**.
4. Если сервер запустился в режиме localhost (только с ПК), нажмите **«Разрешить доступ по сети»** и подтвердите UAC. Это нужно сделать один раз.
5. Скопируйте URL из поля «Для телефона» — он содержит токен доступа.
6. Откройте этот URL в браузере телефона.

Внизу окна TVManager справа появится адрес сервера — его можно использовать, пока программа запущена.

### Что доступно в веб-интерфейсе

- **Пульт** — D-pad, Home, Back, Меню, Поиск, Настройки, Источник, громкость, каналы, медиа, цветные кнопки, цифры, ввод текста. Кнопки поддерживают удержание.
- **Запуск** — список приложений с поиском и фильтрами (Все / Пользовательские / Системные). Кнопка запуска.
- **Пакеты** — управление: отключить / включить / удалить. Фильтры по типам и состоянию, поиск.
- **Питание** — спящий режим, пробуждение, перезагрузка, выключение, клавиша Power.
- **Таймер** — таймер сна на 15/30/45 мин, 1/1.5/2 часа или своё значение.
- **Окна** — текущее активное приложение + список всех запущенных процессов с кнопкой закрытия.
- **Файлы** — проводник по `/sdcard/` и другим путям, скачивание файлов на телефон, удаление.
- **Скриншоты** — снять и посмотреть сразу в модальном окне, снять и сохранить на ПК, галерея последних 30 снимков с превью.
- **Метрики** — CPU, RAM, Storage, температура, uptime, load avg с прогрессбарами + топ-15 процессов по CPU.
- **Пресеты** — тайм-аут экрана, анимация (1x / 0.5x / 0x), отключение OTA — одним кликом.
- **Bluetooth** — состояние, список сопряжённых, включение/выключение.
- **Wi-Fi** — SSID, IP, MAC, шлюз, частота, скорость, сигнал.
- **APK** — загрузка `.apk`, `.apks`, `.xapk`, `.apkm` с телефона → установка через ADB с прогрессбаром.
- **Лог** — логи TVManager в реальном времени с автообновлением.
- **Инфо** — статус подключения, IP ТВ, версия, время сервера.

### Безопасность

Доступ к API защищён токеном, который генерируется при каждом запуске сервера. Без токена API не отвечает. Токен виден в URL и в логах приложения. Сервер доступен только в локальной сети.

## Быстрый старт

### 1. Подготовка телевизора

1. Подключите ТВ к той же Wi-Fi-сети, что и ПК.
2. Настройки → О телевизоре → Сборка → нажать 7 раз (включит режим разработчика).
3. Настройки → Для разработчиков → включить «Отладка по ADB» и «Отладка по сети».
4. Узнать IP-адрес ТВ: Настройки → Сеть → Wi-Fi.

### 2. Подготовка ПК

1. Скачать Platform Tools, распаковать, например, в `C:\platform-tools`.
2. Скачать репозиторий (git clone или ZIP).
3. Запустить `TVManager.bat`.
4. При первом запуске указать папку с `adb.exe`.

### 3. Подключение

1. На главном экране нажать «Настройка».
2. Ввести IP телевизора или нажать «Сканировать».
3. Нажать «Подключиться».
4. На экране ТВ подтвердить запрос «Разрешить отладку по USB».

## Важные предупреждения

- Отключение и удаление системных пакетов может нарушить работу ТВ. Используйте на свой риск, проверяйте через раздел «Откат».
- Удаление `com.tcl.*` сервисов может сломать пульт, PiP или обновления. Начинайте с отключения, а не удаления.
- Отключение стандартного лаунчера оставит ТВ без главного экрана, если сторонний лаунчер не работает. Восстановить можно через кнопки в разделе «Приложения и лаунчеры → Лаунчеры» или через ADB.
- На Google TV (включая TCL) назначение нового лаунчера может потребовать отключения штатного `com.google.android.apps.tv.launcherx`. TVManager не делает это автоматически — покажет инструкцию. Не отключайте `com.google.android.tungsten.setupwraith` — это может привести к сбросу настроек ТВ, включая Wi-Fi.
- Отключение OTA-обновлений останавливает приход новых прошивок.
- Кириллица через `input text` не передаётся. Решается установкой ADBKeyboard, но на некоторых прошивках TCL он не работает — приложение предупредит.
- Wi-Fi переключается только через системное меню ТВ. Если выключить Wi-Fi из приложения при подключении по Wi-Fi — связь разорвётся.
- HTTP-сервер доступен всем устройствам в вашей локальной сети. Не оставляйте его запущенным без необходимости.
- Для трансляции экрана (scrcpy) нужен кабель или стабильный Wi-Fi 5 ГГц. На 2.4 ГГц возможны подтормаживания.
