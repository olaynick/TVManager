# TVManagerTCL

GUI-приложение для настройки и управления телевизорами **TCL на Android TV** через ADB.
Написано на PowerShell + WPF. Не требует установки — запускается одним `.bat`-файлом.

## ✨ Возможности

### 📦 Управление приложениями
- Просмотр всех установленных, системных, сторонних и отключённых пакетов
- **Отключение** рекламных и телеметрических сервисов TCL (`com.tcl.waterfall`, `com.tcl.bi`, `com.tcl.tvwebrs` и др.)
- **Удаление** предустановленного мусора без root (`pm uninstall --user 0`)
- **Восстановление** удалённых пакетов (`cmd package install-existing`)
- **Очистка данных** приложений (`pm clear`)
- Готовые категории: реклама, TCL-сервисы, Google-мусор, системные

### 📥 Установка APK
- Пакетная установка APK из папки
- Фоновая установка (UI не блокируется)
- Установка с флагами `-r -g` (перезапись + автовыдача разрешений)
- Пометка уже установленных APK

### 🗂 Файловый менеджер
- Навигация по файловой системе ТВ (`/sdcard/`, `/storage/`, `/data/`)
- Скачивание и загрузка файлов (`adb pull` / `adb push`)
- Создание и удаление папок
- Быстрые пути: `/`, `/sdcard/`, `/sdcard/Download/`, `/storage/`, `/data/`

### 🎮 Пульт
- Крестовина (DPAD), OK, Back, Home, Menu
- Управление громкостью и mute
- Медиа-кнопки (play/pause, next, prev)
- Ввод текста (`input text`) с предупреждением о кириллице
- Перебор кодов для кнопки «Меню» на разных прошивках

### 📸 Скриншоты и запись видео
- Скриншоты с ТВ одним кликом (`screencap`)
- Запись видео с экрана (`screenrecord`, 15 сек – 10 мин)
- Галерея сохранённых файлов с превью
- Автосохранение в `Desktop\screenshot_tv\`

### 🖥 Сведения об устройстве
- Модель, производитель, серийный номер, MAC
- Версия Android, ядро, патч безопасности, bootloader, fingerprint
- CPU (модель, ядра, архитектура, частоты), GPU
- RAM, Storage (всего / свободно)
- Разрешение экрана, плотность, IP, uptime
- Экспорт в буфер обмена

### 🔋 Питание
- Спящий режим и пробуждение (`KEYCODE_POWER` / `KEYCODE_WAKEUP`)
- Перезагрузка
- Выключение (`reboot -p`)
- Перезагрузка в Recovery / Bootloader

### 📜 Logcat
- Живые логи Android в реальном времени
- Фильтр по подстроке
- Фильтр по уровню (Debug / Info / Warning / Error)
- Сохранение в файл

### 🛠 Сервис — готовые ADB-команды
- Справочник из 100+ готовых команд по категориям:
  - Информация, производительность, сеть, экран, звук
  - Приложения, установка, питание, ввод
  - Wi-Fi, Bluetooth, батарея, отладка, файлы
- Своя команда с подстановкой параметров через диалог

### 👤 Профили устройств
- Сохранение полного состояния ТВ:
  - Отключённые и удалённые пакеты
  - Пакеты, которые должны быть включены
  - Сторонние приложения
  - Масштаб анимации
  - Состояние OTA
- **Экспорт / импорт** профилей в JSON
- **Применение профиля** с автоматической синхронизацией состояния
- Просмотр содержимого профиля перед применением

### ⏪ Откат изменений
- Все действия логируются в `tv_changes_backup.json`
- Каждое изменение хранит команду восстановления
- Массовый откат выбранных действий
- Очистка истории

### ⚙️ Прочие настройки
- **Масштаб анимации** — 1x / 0.5x / 0x (снижение задержек интерфейса)
- **Разблокировка установки APK** (для TCL-прошивок с блокировкой sideload)
- **Отключение OTA** (`com.snm.upgrade`, `com.tcl.versionUpdateApp`)
- **Резервная копия APK** всех сторонних приложений
- **Автоподключение** при запуске к последнему IP

### 🌐 Сканирование сети
- Поиск ТВ в локальной сети: ARP → ping → проверка порта 5555
- Подсветка вероятного телевизора
- Определение ПК и роутера в списке

## 📋 Требования

- **Windows 10 / 11**
- **PowerShell 5.1+** (встроен в Windows 10/11)
- **ADB (Platform Tools)** — [скачать с сайта Google](https://developer.android.com/tools/releases/platform-tools)
- **Телевизор TCL на Android TV** (или другой Android TV) с включённой **отладкой по USB/сети**

Приложение умеет **автоматически добавить ADB в PATH** при первом запуске — просто укажите папку, куда распаковали `platform-tools`.

## 🚀 Быстрый старт

### 1. Подготовка телевизора

1. Включите ТВ и подключите его к той же Wi-Fi-сети, что и ПК.
2. Откройте **Настройки → О телевизоре → Сборка** и нажмите 7 раз (включит режим разработчика).
3. **Настройки → Для разработчиков**:
   - Включите **Отладка по ADB**
   - Включите **Отладка по сети** (если есть)
   - Отключите **Автообновление системы** (опционально)
4. Узнайте IP-адрес ТВ: **Настройки → Сеть → Wi-Fi → IP-адрес**.

### 2. Подготовка ПК

1. Скачайте [Platform Tools](https://developer.android.com/tools/releases/platform-tools).
2. Распакуйте, например, в `C:\platform-tools`.
3. Запустите `TVManager.bat` из корня проекта.
4. При первом запуске приложение попросит указать папку с `adb.exe` — выберите `C:\platform-tools`.
5. Программа добавит ADB в пользовательский `PATH` автоматически.

### 3. Подключение

1. На главном экране нажмите **Настройка**.
2. Введите IP телевизора (или нажмите **Сканировать** для поиска в сети).
3. Нажмите **Подключиться**.
4. **На экране телевизора** появится запрос «Разрешить отладку по USB?» — нажмите **Всегда разрешать** → **ОК**.

Готово! Теперь доступны все разделы.

## ⚠️ Важные предупреждения

- **Отключение и удаление системных пакетов может нарушить работу ТВ.** Используйте на свой риск и всегда проверяйте действие через **Откат**.
- **Удаление `com.tcl.*` сервисов** может сломать пульт, картинку в картинке или обновления. Начинайте с отключения, а не удаления.
- **Список опасных для отключения пакетов**: `com.tcl.bootadservice`, `com.tcl.waterfall` — безопасны. `com.tcl.tvwebrs` — на некоторых прошивках ломает Samsung Smart View. **Тестируйте по одному.**
- **OTA-обновления** при отключении перестают приходить — но и `pm install` для новых прошивок тоже. Держите где-то исходную прошивку.
- **Выключение через `reboot -p`** может не работать на некоторых прошивках — там просто перезагрузится.
- **Кириллица** через `input text` не передаётся — это ограничение ADB, а не приложения.

## 🐛 Известные проблемы

- Дублирование `New-ViewButton` и `New-ViewHeader` в `GuiHelper.ps1` и `ViewHelpers.ps1` — кнопки в некоторых вьюхах теряют явно заданный цвет (исправление в работе).
- `Stop-Logcat` определена дважды — вторая версия перекрывает первую.
- `Invoke-Adb` использует `Command.Split(' ')` — команды с путями, содержащими пробелы, работают некорректно.
- При потере связи статус в шапке может «залипнуть» на «Подключено» до следующего действия.
- `screenrecord` блокирует UI, если запущен не через `ViewScreenshot.ps1`.
