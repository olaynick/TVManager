# TVManagerTCL

GUI-приложение для настройки и управления телевизорами **TCL на Android TV** через ADB.
Написано на PowerShell + WPF. Запускается одним `.bat`-файлом, установка не требуется.

## ✨ Возможности

### 📦 Управление приложениями
- Просмотр всех установленных, системных, сторонних и отключённых пакетов
- **Отключение** рекламных и телеметрических сервисов TCL (`com.tcl.waterfall`, `com.tcl.bi`, `com.tcl.tvwebrs` и др.)
- **Удаление** предустановленного мусора без root (`pm uninstall --user 0`)
- **Восстановление** удалённых пакетов (`cmd package install-existing`)
- **Очистка данных** приложений (`pm clear`)
- Готовые категории: реклама, TCL-сервисы, Google-мусор, системные
- Экран **«Отключённые приложения»** — быстрое возвращение пакетов обратно

### 📥 Установка .apk, .apks, .xapk, .apkm
- Пакетная установка из папки
- Фоновая установка (UI не блокируется)
- Флаги `-r -g -d`: перезапись + автовыдача разрешений + allow-downgrade
- **Человеческие сообщения об ошибках** вместо `INSTALL_FAILED_*` кодов
- Подсказки с командами для обхода ошибок (`VERSION_DOWNGRADE`, `UPDATE_INCOMPATIBLE`)
- Пометка уже установленных APK в списке

### 🗂 Файловый менеджер
- Навигация по файловой системе ТВ (`/sdcard/`, `/storage/`, `/data/`)
- Скачивание и загрузка файлов (`adb pull` / `adb push`)
- Создание и удаление папок
- Быстрые пути: `/`, `/sdcard/`, `/sdcard/Download/`, `/storage/`, `/data/`
- Парсинг через `find -printf` с fallback на `ls -la`

### 🎮 Пульт
- Крестовина (DPAD), OK, Back, Home, Menu
- Управление громкостью и mute
- Медиа-кнопки (play/pause, next, prev)
- **Горячие клавиши с клавиатуры ПК:** ↑↓←→, Enter, Backspace, Esc, Space, +/−, M, P, Delete
- **Ввод текста** с ТВ-клавиатуры ПК
- Интеграция с **ADBKeyboard** для ввода кириллицы (с честной оговоркой о совместимости прошивок)

### 📶 Wi-Fi (только информация)
- Текущее состояние Wi-Fi: вкл/выкл
- SSID, BSSID, IP, MAC, шлюз, DNS, частота, скорость, уровень сигнала
- **Активный интерфейс** — Wi-Fi или Ethernet с IP
- Список доступных сетей
- Кнопка «Открыть настройки Wi-Fi на ТВ» (переключение только через системное меню, чтобы не разорвать ADB-соединение)

### 🖥 Разрешение и DPI
- Текущее разрешение и плотность (физическое + override)
- Пресеты: 720p / 1080p / 1440p / 4K
- Пресеты DPI: 160 / 240 / 320 / 480
- Кастомные значения через диалог
- Кнопки «Только размер» и «Размер + DPI»
- Сброс override к заводским значениям
- Каждое изменение сохраняется в историю отката

### ⚙️ Пресеты настроек
**30 готовых пресетов в 3 вкладках:**

- **Экран:** тайм-аут (5 мин – никогда), яркость (25% – 100% / авто), immersive-режим
- **Интерфейс:** анимации (1x / 0.5x / 0.25x / 0x), показ касаний, границы макета, GPU-рендеринг
- **Система:** питание (stay awake, отключение блокировки), звук (safe volume), ADB-настройки, скрытие значков уведомлений

### 📸 Скриншоты и запись видео
- Скриншоты с ТВ одним кликом (`screencap`)
- Запись видео с экрана (`screenrecord`, 15 сек – 10 мин)
- **Живой прогресс-бар** во время записи
- Галерея сохранённых файлов с превью
- Автосохранение в `Desktop\screenshot_tv\`

### 🖥 Сведения об устройстве
- Модель, производитель, серийный номер, MAC
- Версия Android, ядро, патч безопасности, bootloader, fingerprint
- CPU (модель, ядра, архитектура, частоты), GPU
- RAM, Storage (всего / свободно)
- Разрешение экрана, плотность, IP, uptime
- **Экспорт полного дампа в JSON или TXT** — все данные + пакеты + настройки + история изменений

### 🧩 Проверка целостности
- Сравнение текущего состояния ТВ с сохранённым дампом
- Показывает: что установлено, удалено, отключено, включено обратно
- 4 группы различий с цветовой кодировкой
- Сохранение отчёта в TXT

### 📊 Процессы ТВ
- Топ-30 процессов по CPU или памяти
- PID, CPU%, RAM, имя процесса
- Кнопка **«Стоп»** — `am force-stop` для пакетов `com.*`
- Сводка по оперативной памяти с прогресс-баром

### 🔋 Питание
- Спящий режим и пробуждение (`KEYCODE_POWER` / `KEYCODE_WAKEUP`)
- Перезагрузка
- Выключение (`reboot -p`)
- Перезагрузка в Recovery / Bootloader
- Ожидание отключения ТВ после команды (до 15 сек)

### 📜 Logcat
- Живые логи Android в реальном времени
- Фильтр по подстроке и уровню (Debug / Info / Warning / Error)
- Цветовая подсветка по уровню
- Сохранение в файл

### 🛠 Сервис — 100+ готовых ADB-команд
Категории:
- **Информация** — модель, версия, серийник, патч безопасности, fingerprint
- **Производительность** — CPU, память, диски, температура, uptime
- **Сеть** — интерфейсы, DNS, ping, traceroute, netstat
- **Экран** — разрешение, яркость, тайм-аут, ориентация
- **Звук** — громкость, mute, регулировка
- **Приложения** — пакеты, версии, разрешения, пути к APK
- **Установка** — install, uninstall, pm path
- **Ввод** — keyevent, swipe, tap, text
- **Wi-Fi / Bluetooth** — вкл/выкл, MAC, сканирование
- **Отладка** — dumpsys, logcat, top, dmesg
- **Специальные** — immersive, DPI, скрытие статус-бара
- **Своя команда** — ввод вручную с подстановкой параметров `<...>`

### 👤 Профили устройств
- Сохранение полного состояния ТВ: отключённые/удалённые/включённые пакеты, сторонние приложения, анимация, OTA
- **Применение профиля** с автоматической синхронизацией состояния
- Экспорт / импорт профилей в JSON
- Просмотр содержимого профиля

### ⏪ Откат изменений
- Все действия логируются в `tv_changes_backup.json`
- Каждое изменение хранит команду восстановления
- Массовый откат выбранных действий
- Очистка истории

### ⚙️ Настройки приложения
- **Автоподключение** к последнему IP при запуске
- **Авто-сканирование сети** при неудачном автоподключении
- Профили устройств (список сохранённых)
- Путь к `config.json`
- **Открыть папку с логами** + **Скопировать лог** в буфер
- Сброс настроек

### 🌐 Сканирование сети
- Поиск ТВ в локальной сети: ARP → ping → проверка порта 5555
- Подсветка вероятного телевизора
- Определение ПК и роутера в списке

## 📋 Требования

- **Windows 10 / 11**
- **PowerShell 5.1+** (встроен в Windows 10/11)
- **ADB (Platform Tools)** — [скачать с сайта Google](https://developer.android.com/tools/releases/platform-tools)
- **Телевизор TCL на Android TV** (или другой Android TV) с включённой **отладкой по USB/сети**

Приложение умеет **автоматически добавить ADB в PATH** при первом запуске — просто укажите папку, куда распаковали `platform-tools`.

## 🚀 Быстрый старт

### 1. Подготовка телевизора

1. Включите ТВ и подключите его к той же Wi-Fi-сети, что и ПК.
2. Откройте **Настройки → О телевизоре → Сборка** и нажмите 7 раз (включит режим разработчика).
3. **Настройки → Для разработчиков**:
   - Включите **Отладка по ADB**
   - Включите **Отладка по сети** (если есть)
   - Отключите **Автообновление системы** (опционально)
4. Узнайте IP-адрес ТВ: **Настройки → Сеть → Wi-Fi → IP-адрес**.

### 2. Подготовка ПК

1. Установите [Platform Tools](https://developer.android.com/tools/releases/platform-tools), распакуйте, например, в `C:\platform-tools`.
2. Скачайте репозиторий: `git clone <url>` (или распакуйте ZIP).
3. Запустите `TVManager.bat` из корня проекта.
4. При первом запуске приложение попросит указать папку с `adb.exe` — выберите `C:\platform-tools`.
5. Программа добавит ADB в пользовательский `PATH` автоматически.

### 3. Подключение

1. На главном экране нажмите **Настройка**.
2. Введите IP телевизора (или нажмите **Сканировать** для поиска в сети).
3. Нажмите **Подключиться**.
4. **На экране телевизора** появится запрос «Разрешить отладку по USB?» — нажмите **Всегда разрешать** → **ОК**.

Готово! Теперь доступны все разделы.

## ⚠️ Важные предупреждения

- **Отключение и удаление системных пакетов может нарушить работу ТВ.** Используйте на свой риск и всегда проверяйте действие через **Откат**.
- **Удаление `com.tcl.*` сервисов** может сломать пульт, картинку в картинке или обновления. Начинайте с отключения, а не удаления.
- **OTA-обновления** при отключении перестают приходить — но и `pm install` для новых прошивок тоже. Держите где-то исходную прошивку.
- **Выключение через `reboot -p`** может не работать на некоторых прошивках — там просто перезагрузится.
- **Кириллица** через `input text` не передаётся — это ограничение ADB. Решается установкой ADBKeyboard, но на некоторых прошивках TCL он тоже не работает (приложение предупредит).
- **Wi-Fi** переключается только через системное меню ТВ. Если выключить Wi-Fi из приложения при подключении по Wi-Fi — связь разорвётся, и вернуть её можно только с пульта.

## 🐛 Известные ограничения

- **ADBKeyboard** может не работать на некоторых прошивках TCL — система блокирует ввод через сторонние IME. Приложение предупредит об этом.
- **`svc wifi enable/disable`** требует root на некоторых прошивках — приложение работает только в режиме чтения.
- **`screenrecord`** имеет лимит 3 минуты на уровне системы Android, если не задан `--time-limit` явно.
