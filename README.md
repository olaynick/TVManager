# TVManagerTCL

GUI-приложение для настройки и управления телевизорами **TCL на Android TV** через ADB.
Написано на PowerShell + WPF. Запускается одним `.bat`-файлом, установка не требуется.

---

## Возможности

### Управление приложениями
- Просмотр всех установленных, системных, сторонних и отключённых пакетов
- Отключение рекламных и телеметрических сервисов TCL
- Удаление предустановленного мусора без root (`pm uninstall --user 0`)
- Восстановление удалённых пакетов (`cmd package install-existing`)
- Очистка данных приложений (`pm clear`)
- 6 категорий: Реклама и слежка, Стриминг и медиа, Лаунчеры, TCL-сервисы, Google-мусор, Системные
- Маркировка рисков: зелёный (безопасно), оранжевый (осторожно), красный (может сломать ТВ)
- Двойное подтверждение при отключении опасных пакетов
- Экран «Отключённые приложения» для быстрого возврата пакетов
- Поиск по всем категориям сразу
- Отдельная вкладка «Лаунчеры» с предупреждением и кнопками восстановления стандартных лаунчеров (Google TV, TCL)

### Установка APK
- Пакетная установка `.apk`, `.apks`, `.xapk`, `.apkm`
- Фоновая установка — UI не блокируется
- Флаги `-r -g -d`: перезапись, автовыдача разрешений, allow-downgrade
- Человеческие сообщения об ошибках вместо `INSTALL_FAILED_*` кодов
- Подсказки с командами для обхода ошибок
- Установка APK, лежащего на самом ТВ (обход SELinux через `/data/local/tmp/`)
- Установка bundle-файлов через `install-multiple`
- Пометка уже установленных APK в списке

### Файловый менеджер
- Навигация по `/sdcard/`, `/storage/`, `/data/`
- Скачивание и загрузка файлов (`adb pull` / `adb push`)
- Создание и удаление папок
- Быстрые пути: `/`, `/sdcard/`, `/sdcard/Download/`, `/storage/`, `/data/`
- Установка APK прямо из файлового менеджера

### Пульт
- Крестовина, OK, Back, Home, Menu
- Управление громкостью и mute
- Медиа-кнопки (play/pause, next, prev)
- Горячие клавиши с клавиатуры ПК: стрелки, Enter, Backspace, Esc, Space, +/-, M, P, Delete
- Ввод текста с ПК
- Интеграция с ADBKeyboard для ввода кириллицы (с предупреждением о совместимости прошивок)

### Wi-Fi (только информация)
- Состояние Wi-Fi: вкл/выкл
- SSID, BSSID, IP, MAC, шлюз, DNS, частота, скорость, уровень сигнала
- Активный интерфейс (Wi-Fi или Ethernet) с IP
- Список доступных сетей
- Кнопка открытия системных настроек Wi-Fi на ТВ

### Разрешение и DPI
- Текущее разрешение и плотность (физическое + override)
- Пресеты: 720p, 1080p, 1440p, 4K
- Пресеты DPI: 160, 240, 320, 480
- Кастомные значения через диалог
- Сброс override к заводским
- Каждое изменение сохраняется в историю отката

### Пресеты настроек
30 готовых пресетов в 3 вкладках:
- **Экран:** тайм-аут (5 мин – никогда), яркость (25% – 100% / авто), immersive-режим
- **Интерфейс:** анимации (1x / 0.5x / 0.25x / 0x), показ касаний, границы макета, GPU-рендеринг
- **Система:** питание, звук, ADB-настройки, скрытие значков уведомлений

### Сценарии (пакетный режим)
- Создание сценариев из последовательности шагов
- 12 типов шагов: отключение/включение/удаление пакета, установка APK, изменение настроек, отправка клавиш и текста, пауза, скриншот, перезагрузка
- Редактор с перемещением шагов, редактированием, удалением
- Экспорт и импорт сценариев в JSON
- Запуск одной кнопкой — все логи в основном окне

### Автозапуск и фон
- Список приложений с фоновой активностью и автозапуском
- Управление через `cmd appops`: разрешить/запретить фон, разрешить/запретить автозапуск
- Форс-стоп приложения при запрете фона
- Массовые пресеты: ограничить все пользовательские, сбросить все
- Поиск по пакетам

### Скриншоты и запись видео
- Скриншоты с ТВ (`screencap`)
- Запись видео (`screenrecord`, 15 сек – 10 мин)
- Живой прогресс-бар при записи
- Галерея с превью
- Автосохранение в `Desktop\screenshot_tv\`

### Сведения об устройстве
- Модель, производитель, серийный номер, MAC
- Версия Android, ядро, патч безопасности, bootloader, fingerprint
- CPU, GPU, RAM, Storage
- Разрешение экрана, плотность, IP, uptime
- Экспорт полного дампа в JSON или TXT

### Проверка целостности
- Сравнение текущего состояния ТВ с сохранённым дампом
- Что установлено, удалено, отключено, включено обратно
- Сохранение отчёта в TXT

### Процессы ТВ
- Топ-30 процессов по CPU или памяти
- PID, CPU%, RAM, имя процесса
- Остановка приложения (`am force-stop`)
- Сводка по оперативной памяти

### Питание
- Спящий режим и пробуждение
- Перезагрузка
- Выключение (`reboot -p`)
- Перезагрузка в Recovery / Bootloader

### Logcat
- Живые логи Android в реальном времени
- Фильтр по подстроке и уровню
- Цветовая подсветка
- Сохранение в файл

### Сервис — 100+ готовых ADB-команд
Категории: Информация, Производительность, Сеть, Экран, Звук, Приложения, Установка, Ввод, Wi-Fi, Bluetooth, Отладка, Специальные. Плюс поле для своей команды с подстановкой параметров.

### Профили устройств
- Сохранение полного состояния ТВ
- Применение профиля с автоматической синхронизацией
- Экспорт и импорт профилей
- Просмотр содержимого профиля перед применением

### Откат изменений
- Все действия логируются в `tv_changes_backup.json`
- Каждое изменение хранит команду восстановления
- Массовый откат выбранных действий
- Очистка истории

### Настройки приложения
- Автоподключение к последнему IP
- Авто-сканирование сети при неудачном автоподключении
- Список сохранённых профилей
- Путь к `config.json`
- Открытие папки с логами, копирование лога в буфер
- Сброс настроек

### Сканирование сети
- Поиск ТВ в локальной сети: ARP, ping, проверка порта 5555
- Подсветка вероятного телевизора
- Определение ПК и роутера

### Справка
- Вкладка «О программе» — описание
- Вкладка «Как подключить ТВ» — 5 шагов + решение типовых проблем
- Вкладка «Возможности» — список всех экранов с указанием, где их найти

## Требования

- Windows 10 / 11
- PowerShell 5.1+ (встроен в Windows)
- ADB (Platform Tools) — скачать с сайта Google
- Телевизор TCL на Android TV (или другой Android TV) с включённой отладкой по USB/сети

Приложение умеет автоматически добавить ADB в PATH при первом запуске.

## Быстрый старт

### 1. Подготовка телевизора

1. Подключите ТВ к той же Wi-Fi-сети, что и ПК.
2. Настройки → О телевизоре → Сборка → нажать 7 раз (включит режим разработчика).
3. Настройки → Для разработчиков → включить «Отладка по ADB» и «Отладка по сети».
4. Узнать IP-адрес ТВ: Настройки → Сеть → Wi-Fi.

### 2. Подготовка ПК

1. Скачать Platform Tools, распаковать, например, в `C:\platform-tools`.
2. Скачать репозиторий (git clone или ZIP).
3. Запустить `TVManager.bat`.
4. При первом запуске указать папку с `adb.exe`.

### 3. Подключение

1. На главном экране нажать «Настройка».
2. Ввести IP телевизора или нажать «Сканировать».
3. Нажать «Подключиться».
4. На экране ТВ подтвердить запрос «Разрешить отладку по USB».

## Важные предупреждения

- Отключение и удаление системных пакетов может нарушить работу ТВ. Используйте на свой риск, проверяйте через раздел «Откат».
- Удаление `com.tcl.*` сервисов может сломать пульт, PiP или обновления. Начинайте с отключения, а не удаления.
- Отключение стандартного лаунчера оставит ТВ без главного экрана, если сторонний лаунчер не работает. Восстановить можно через кнопки в разделе «Управление пакетами → Лаунчеры» или через ADB.
- Отключение OTA-обновлений останавливает приход новых прошивок.
- Кириллица через `input text` не передаётся. Решается установкой ADBKeyboard, но на некоторых прошивках TCL он не работает — приложение предупредит.
- Wi-Fi переключается только через системное меню ТВ. Если выключить Wi-Fi из приложения при подключении по Wi-Fi — связь разорвётся.

## Известные ограничения

- ADBKeyboard может не работать на некоторых прошивках TCL.
- `svc wifi enable/disable` требует root на некоторых прошивках — приложение работает в режиме чтения.
- `screenrecord` имеет лимит 3 минуты на уровне системы Android.
- Отключение фоновой активности через `appops` не поддерживается на очень старых прошивках.
